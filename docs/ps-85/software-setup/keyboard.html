Keyboard Setup

Overview​

The BM43 documentation is somewhat confusing. No matter what I did I couldn't get the keyboard to work with usevia.app. During my troubleshooting I flashed the VIA firmware, however the PCB might actually come with it pre-flashed as I discovered I was able to configure it with the Keychron configuration app instead of the official VIA app. If anyone figures out more details, let me know so I can update the docs!

1. Connect with the Keychron App​

  1. Download the keyboard layout JSON file. I have a working one in the repo in ps-85/software/keyboard.
  2. Plug in the keyboard and navigate to https://launcher.keychron.com/.
  3. Click "Connect".
  4. Choose the BM43 in the dialog and click "Connect"
  5. When prompted choose the JSON file you downloaded in step 1.
